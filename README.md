The Wii U local shop is a Local eShop that runs form your pc

How to set up

First Download the files For Wii u Local shop

and also get node.js make sure to get legacy tools when Installig from the node.js installer

Then open cmd and type. cd /d [Your Path here]

Then type. npm install basic-ftp on cmd

And then go into the Start.js and open it with notepad

and edit const WIIU_IP = process.env.WIIU_IP || "YOURWIIUIPHERE"; const WIIU_FTP_PORT = YOURWIIUPORTHERE; with your Wii U ip and Port you can find that with ftpiiu 

and in cmd type node start.js

and There its done
